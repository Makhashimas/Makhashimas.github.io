# Makhashimas.github.io — Root GitHub Pages site

Root site for **makhashimas.github.io**. It hosts the public pages required for the
**Hermes** personal automation assistant's **Google OAuth consent screen verification**:

- `index.html` — the Hermes app homepage (what the app does, who it's for, how it works)
- `privacy.html` — the privacy policy required by Google for OAuth verification
- `robots.txt` — crawler rules

**🔗 Live:** https://makhashimas.github.io/

---

## About Hermes

Hermes is a **private, single-user** automation assistant that runs on the operator's
own computer. It keeps the operator's personal finance ledger up to date by reading
their own bank transaction notification emails and recording each transaction in their
own Google Sheet — no other users, no public product.

The public pages here exist so Google can review the OAuth application and its privacy
policy.

---

## 🚀 Deployment

Served by **GitHub Pages** from the repository root of `Makhashimas.github.io`
(the user's root Pages site). Push to `main` and it redeploys automatically.
