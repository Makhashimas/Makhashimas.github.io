HERMES

Personal automation assistant · Built and operated by Farrel Fayzul Haqqi · Surabaya, Indonesia

Hermes is a private, single-user automation assistant that runs on the operator's own computer. It keeps the operator's personal finance ledger up to date by reading their own bank transaction notification emails and recording each transaction in their own Google Sheet.

Who it is for: Hermes is used by one person only — its operator. It is not a commercial product, it is not offered to the public, and it has no other users. It is a personal tool built to automate a repetitive bookkeeping task.

WHAT HERMES DOES

READS TRANSACTION EMAILS

Checks the operator's own Gmail for automated bank notifications (for example, BNI) and extracts the amount, time, and merchant.

UPDATES THE LEDGER

Appends each new transaction as a row in the operator's personal Google Sheet, without creating duplicates.

SENDS A SUMMARY

Emails the operator a periodic summary of their own spending, and posts an update to their private Discord channel.

BUILDS REMINDERS

Optionally creates Google Calendar reminders and short Google Docs notes for the operator.

HOW IT WORKS

  • The operator signs in with Google once and grants Hermes access to their own account.
  • Hermes runs on a schedule on the operator's own machine and calls Google APIs on the operator's behalf.
  • All data stays in the operator's own Google account — Hermes does not run any server that stores user data.

GOOGLE SERVICES USED

  • Gmail (read, modify, send) — to read bank notifications and send the operator their own summaries.
  • Google Sheets — to maintain the operator's personal transaction ledger.
  • Google Drive & Docs — to create and manage the ledger file and optional summaries.
  • Google Calendar — to add personal reminders.
  • Google Contacts (read-only) — to label the operator's own messages.

PRIVACY

Hermes uses Google user data only to provide the features described above. It does not sell or share data, does not use it for advertising, and does not use it to train AI models. Full details are in the privacy policy.
